# users_frontend

Этот репозиторий содержит фронтенд приложение для нашей веб-платформы.

## Предварительные требования
- На вашем компьютере должны быть установлены Node.js и npm. Вы можете скачать и установить их с https://nodejs.org.

## Установка
1. Клонируйте этот репозиторий на ваше локальное устройство
2. Откройте терминал и перейдите в директорию проекта
3. Выполните команду ```npm install``` для установки всех необходимых зависимостей

## Запуск приложения
1. После завершения установки, выполните команду ```npm run dev``` в терминале
2. В терминале появится ссылка на порт, на котором запущен проект. Обычно это http://localhost:5173
